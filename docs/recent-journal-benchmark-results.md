## 历史 20 篇先导结果

> 数据窗口：2026-01-01 至 2026-06-30

## 结论

这次 20 篇近期论文的小规模先导实验中，系统的最终 Hit@10 为 **15%**。标题+摘要轨道的 Hit@1 为 **10%**、MRR@10 为 **0.125**；仅摘要轨道的 Hit@1 为 **5%**、MRR@10 为 **0.100**。

主要瓶颈不是最终重排，而是召回：两个轨道的 Preliminary Hit@40 都只有 **15%**。真实期刊一旦进入初排 Top-40，三个可计分命中都被 Search API + LLM 重排推进到最终 Top-3；但其余 17/20 个真实期刊没有进入初排 Top-40，最终层通常无从补救。因此下一步应优先扩充全学科期刊的收稿范围文本和向量表示，并扩大或分层生成重排候选，而不是继续微调最后十名的解释提示词。

## 数据集

- 来源：Crossref REST API 的 `journal-article` 元数据，只取 DOI、标题、摘要、发布日期、期刊与 ISSN，不下载论文全文；
- 抽样：20 篇论文来自 20 个不同期刊，覆盖 9 个宽领域；
- 分区：JCR Q1、Q2、Q3、Q4 各 5 篇；
- 标签映射：本轮是从系统候选目录反向分层抽样，再用 Crossref ISSN 校验并在评测时重新解析当前实体，20/20 映射成功；因此 100% 是目录内一致性检查，不代表外部论文总体的目录覆盖率；
- 候选空间：同时检索全部 20,087 个 JCR Q1–Q4 期刊实体，没有使用真实领域或真实分区缩小范围；
- 输入轨道：`title_abstract` 和 `abstract_only`，真实期刊名称、ISSN、分区均不进入查询。

20 个样本的 Hit@10=15% 对应 3 次命中，其 Wilson 95% 区间约为 **5.2%–36.0%**。因此这是一轮能定位问题的先导实验，不应被解读成稳定的总体性能估计；要比较后续版本，建议至少扩展到 200–500 篇并保持相同时间窗、种子和分层方法。

## 命中与重排

最终 Top-10 的三个真实期刊如下：

| 真实期刊 | 初排 → 最终（标题+摘要） | 初排 → 最终（仅摘要） |
| --- | ---: | ---: |
| International Journal of Workplace Health Management | 27 → 2 | 22 → 2 |
| Journal of Time Series Analysis | 7 → 1 | 7 → 2 |
| Time & Society | 3 → 1 | 3 → 1 |

这说明融合重排对已召回候选有效：最终 Hit@10 比初排 Hit@10 提升 5 个百分点，MRR@10 分别提升约 0.101 和 0.076。与此同时，扩大最终重排本身无法解决未进入 Top-40 的 85% 样本。

## Search 泄漏

Search API 证据可能直接暴露 DOI、近乎相同的论文标题或真实期刊名。本次审计发现：

- 标题+摘要：8/20 出现 DOI 或近似标题泄漏；严格无任何身份泄漏子集 12 篇，Hit@10 为 16.7%；
- 仅摘要：12/20 出现 DOI 或近似标题泄漏；严格无任何身份泄漏子集 8 篇，Hit@10 为 37.5%；
- 更保守的下界把所有被标记样本保留在分母并一律记为未命中：标题+摘要 Hit@10 为 **10%**，仅摘要 Hit@10 为 **15%**。

“仅摘要”仍会泄漏，是因为长摘要中的独特措辞足以让搜索引擎定位原论文。无泄漏子集很小且不是随机子样本，其 37.5% 不能直接与总体 15% 比较。LLM 也可能记忆公开论文，这一残余泄漏无法仅靠 Search 证据审计完全排除。

## 延迟

常驻 worker 的一次性预热约 17 秒，不计入每条查询。端到端结果为：

| 轨道 | 初排中位数 | 初排 P90 | 最终中位数 | 最终 P90 |
| --- | ---: | ---: | ---: | ---: |
| 标题 + 摘要 | 3.48 s | 4.61 s | 4.51 s | 7.34 s |
| 仅摘要 | 3.23 s | 4.50 s | 4.23 s | 5.57 s |

上表是修正后复跑的暖缓存耗时，不能代表首次遇到新主题的冷查询。第一次冷运行的成功查询中位数约为 26–27 秒、P90 为 35–41 秒，且曾出现一次 192 秒的 LLM 读取超时；断点重试后成功。暖缓存把 LLM 规划、向量查询和 Search/重排结果复用后，中位数降到约 4–5 秒。生产评估应同时报告冷、暖两种延迟。

## 解释边界与改进优先级

真实发表期刊只是一个自然正标签。未命中不等于系统推荐的其他期刊不适合，命中也不表示该期刊是今天唯一或最佳的投稿选择。这个实验衡量“目录内历史期刊条件恢复”，不是完整的推荐满意度或独立目录覆盖率。

抽样还受 Crossref `has-abstract` 覆盖、每刊最新一页、每刊最多一篇和出版社元数据质量影响。它更接近期刊宏平均的分层先导集，不代表现实论文流量分布。

建议依次推进：

1. 继续给 20,087 个 JCR 候选补充期刊 aims & scope、主题词和文章类型；本轮初始快照为 151/20,087（0.752%），后续产品 scope 并集已达 420/20,087（2.091%）。历史论文证据另已覆盖 19,593/20,087（97.54%），但它不等于官方 scope，且派生 PCL 画像在因果清洁重建前不能用于正式论文结论。
2. 将初排从单一全局 Top-40 改为多通道配额合并，例如向量、LightRAG 实体、分类邻域和 LLM 领域路由各保留候选，再去重进入重排。
3. 建立 Search 隔离轨道：搜索词只包含主题概念，不携带原题和长摘要原句；同时保留当前生产轨道，用于衡量真实用户体验。
4. 扩展到至少 200–500 篇；另做领域专家盲评 Top-5，评价其他合理期刊，补充 nDCG 和评审一致性。

复现方法见[评测协议](recent-journal-benchmark.md)。原始数据和逐条输出默认位于 `benchmark_artifacts/recent_journals/`，其中摘要可能受各权利人版权约束，因此该目录不提交 Git。
