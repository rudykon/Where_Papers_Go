# Where Papers Go 性能与离线效果评测

> 评测日期：2026-08-14（Asia/Shanghai）
> 原则：延迟优化不得减少候选、跳过强制通道或将失败样本移出分母。

## 1. 结论摘要

- 精确向量召回已从 Python 标量遍历改为预加载 NumPy 矩阵乘法。对 20,087 个 JCR Q1–Q4 候选返回 Top-500，稳态 p50 从 `793.78 ms` 降为 `27.65 ms`，加速 `28.71×`。
- 20 个真实缓存语义查询的 Top-40 顺序和 Top-500 候选集合全部与标量实现一致；唯一顺序差异发生在某查询第 473 名后的近同分候选，最大分数误差 `1.53e-7`。
- 新建的 Search-free 时间评测包含 4,791 篇论文和完整 20,087 候选。在 2,161 篇 2026-06 测试论文上，当前最强词法基线 TF-IDF 的 Hit@10 为 `16.24%`、nDCG@10 为 `10.22%`。
- 这些结果支持“工程提速无可测 Top-40 质量下降”，但不支持“SCOPE-Rank 已优于强基线”。自适应路由、稠密/图通道和校准拒答仍需要按路线图做完整消融。

## 3. 精确向量召回

### 3.1 延迟

| 实现 | p50 | p90 | 相对标量 p50 |
| --- | ---: | ---: | ---: |
| Python scalar | 793.78 ms | 815.73 ms | 1.00× |
| NumPy，大子集优化后 | 27.65 ms | 30.22 ms | **28.71×** |

这些数字只包含本地向量扫描，不包含 LLM、LightRAG 或 Search API 网络时间。优化前的 NumPy 子集索引路径 p50/p90 为 `44.27/50.34 ms`；改为“先全矩阵乘法，后筛选分数”后又降低 `37.5%/40.0%`，同时避免每次查询复制大部分向量矩阵。

### 3.2 质量非劣

| 检查 | 结果 |
| --- | ---: |
| Top-10 / Top-40 / Top-100 顺序一致 | 20/20 |
| Top-500 候选集合一致 | 20/20 |
| Top-500 逐位顺序一致 | 19/20 |
| 最大余弦分数误差 | `1.53e-7` |

因此可以声称“实际重排使用的 Top-40 完全一致”，不应声称“所有 Top-500 位置逐位一致”。

### 3.3 冷启动边界

独立冷态测量中，图打开约 `3.254 s`，向量解码和矩阵预加载约 `3.820 s`。预加载后的首次 BLAS 查询约 `147 ms`，之后进入 28 ms 左右的 JCR 稳态。预加载是将成本前移到 worker 启动，而不是消除进程总冷启动成本。

## 4. Search-free 时间评测

### 4.1 协议

- 论文：4,791 篇具有题目、摘要、精确 ISSN 期刊映射和日/月精度发表日期的 Crossref 缓存记录。
- 时间切分：训练 1,086（2026-01至03），验证 1,544（04至05），测试 2,161（06）。
- 候选：完整 20,087 个 JCR Q1–Q4 期刊，金标目标目录覆盖率 100%。
- 档案：仅用 2025 榜单的名称/学科和截止日前历史论文；不使用当前金标优先补全的 scope。
- 外部服务：0 次 LLM/Search 调用；泄漏审计无 critical finding。
- 覆盖局限：只有 181/20,087（`0.90%`）候选拥有截止日前的缓存历史论文。

> 上述 `181/20,087` 是本页 2026-08-14 旧缓存实验的冻结口径，不是当前采集状态。2026-08-24 已完成的新语料在 19,593/20,087 个候选上有历史论文（97.54%）；在因果清洁重建和新语料正式 run 完成前，本页的旧指标仍只作回归对照。

### 4.2 完整测试分母结果

| 方法 | Hit@1 | Hit@10 | Hit@50 | MRR@10 | nDCG@10 |
| --- | ---: | ---: | ---: | ---: | ---: |
| BM25 | 2.55% | 11.24% | 21.75% | 4.84% | 6.34% |
| RRF(BM25, TF-IDF) | 3.70% | 13.84% | 24.80% | 6.51% | 8.24% |
| Learned linear fusion | 4.35% | 14.99% | 25.82% | 7.33% | 9.14% |
| **TF-IDF** | **5.23%** | **16.24%** | **26.33%** | **8.36%** | **10.22%** |

学习融合显著超过 BM25，但没有超过最强的 TF-IDF 基线。这是论文升级的有用负结果：当历史档案覆盖只有 0.90% 时，只学习两个词法通道不足以成为方法贡献。下一步必须补全全库冻结档案，再导入 dense、LightRAG 和属性图运行做公平融合。

其中 46 个测试查询的输入文本显式出现了归一化金标期刊名。不静默删除这些样本，主表仍使用 2,161 全分母；额外的 identity-safe 敏感性分母为 2,115，TF-IDF Hit@10 为 `15.65%`。学习融合相对 TF-IDF 的 nDCG@10 差值为 `-0.01080`，95% 配对 bootstrap CI 为 `[-0.01402, -0.00769]`，双侧置换检验 `p=0.00050`，即当前融合确实显著弱于 TF-IDF，不是抽样波动造成的假象。

### 4.3 历史画像与 JCR 分区分层

下表仍以完整 2,161 篇 test 为主分母，只将同一批查询按金标期刊的训练历史数分组：`warm >= 5`、`few-shot = 1--4`、`cold = 0`。

| 方法 | Cold Hit@10（n=1,659） | Few-shot Hit@10（n=215） | Warm Hit@10（n=287） |
| --- | ---: | ---: | ---: |
| BM25 | 3.56% | 42.33% | 32.40% |
| RRF | 3.98% | 46.05% | 46.69% |
| Learned linear | 4.10% | 46.51% | 54.36% |
| **TF-IDF** | **4.34%** | **46.51%** | **62.37%** |

这个差距说明画像覆盖是当前首要瓶颈：当金标期刊达到 warm 时，TF-IDF Hit@10 为 `62.37%`；cold 期刊只有 `4.34%`。同一评测按 JCR 分区的 TF-IDF Hit@10 为 Q1 `12.42%`、Q2 `16.41%`、Q3 `11.24%`、Q4 `27.15%`，因此后续结果不能只报总平均。

新评测器会自动输出 `by_history_status`、`by_profile_level`、`by_subject` 和 `by_jcr_quartile`。旧缓存没有冻结的画像证据等级和可用学科字段，因此这两个维度当前会显式记为 `unknown`，待新的多来源多原型画像重建后再填充，不会从分母中删除。

## 5. 现有 500 篇产品评测的解读边界

旧在线评测的成功样本条件 Hit@10 为 18.1%（49/271），但 500 个全分母 Hit@10 只有 9.8%，并且 Search 身份泄漏安全下界为 3.8%。它与本文的 Search-free 时间评测不是同一任务，不应直接比较百分比；旧结果仅作为产品回归下界。

为了给原 500 篇集合一个可比的无泄漏对照，使用相同冻结期刊档案单独评测其 2026-06 测试子集。全集 499/500 金标能映射到冻结目录，缺失样本未从分母中删除。

| 方法 | June test Hit@10（n=337） | Identity-safe Hit@10（n=333） |
| --- | ---: | ---: |
| BM25 | 7.72% | 7.51% |
| Learned linear | 8.90% | 8.71% |
| TF-IDF | 9.50% | 9.01% |
| RRF | 9.50% | **9.31%** |

在这个较小子集上，RRF 与 TF-IDF 的 nDCG@10 差异不显著（双侧置换检验 `p=0.378`）。
