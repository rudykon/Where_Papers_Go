# IEEE INFOCOM 2022–2026：通信网络流量预测论文集

本合集覆盖截至 2026-07-31 已举行的五届 IEEE INFOCOM（2022–2026）。主题限定为通信网络中的流量负载、吞吐量、移动网络 KPI 与网络管理预测；不纳入道路车流预测。

## 已下载内容

`论文PDF/` 中现有 7 篇作者或作者机构明确公开的 PDF：其中 5 篇为 INFOCOM 正式主会论文，另有 1 篇 INFOCOM Workshop 和 1 篇 INFOCOM Poster。文件名遵循：

`序号_年份_会议简称年份_中文题名_第一作者等.pdf`

例如：`01_2023_INFOCOM2023_从可解释AI视角识别移动流量预测中深度神经网络的脆弱性_Moghadas等.pdf`。

## 范围说明

- 核心方向：移动网络流量/载波流量需求预测、网络管理中的流量预测，以及 Open RAN 流量负载预测。
- 邻近方向：WLAN 吞吐量预测。该方向与流量预测的建模和资源调度紧密相关，单列为“邻近主题”。
- `待获取_无公开PDF候选.tsv` 收录检索到但未找到作者合法公开 PDF 的高度相关 INFOCOM 主会论文（含 DOI 和作者公开代码链接）。这些条目没有下载 IEEE Xplore 等受限版本。
