# IEEE INFOCOM 2024–2026：基站通信资源论文集

截至 2026-07-31，INFOCOM 2027 尚未举行；本集合将“近三年”界定为已经举办的 IEEE INFOCOM 2024、2025、2026。

本目录包含 20 篇与基站/无线接入网资源紧密相关的论文：频谱与波束资源、O-RAN/vRAN 编排、网络切片、无线单元能耗、无线信道/无线电地图、蜂窝-雷达共存，以及基站侧或邻近边缘的计算与接入资源调度。

## 目录与命名

20 篇公开 PDF 均在 `论文PDF/` 中，命名规则为：

`序号_年份_会议简称年份_中文题名_第一作者等.pdf`

例如：

`01_2024_INFOCOM2024_ORANUS：基于随机网络演算的6G O-RAN时延定制化编排_Adamuz-Hinojosa等.pdf`

其中第 11 篇来自 IEEE INFOCOM 2025 Workshop，因此使用 `INFOCOMW2025`；其余来自 INFOCOM 正式论文集。`sources.tsv` 给出原题、作者、DOI、主题分类、arXiv ID、公开 PDF 链接和会议归属证据。`CHECKSUMS.sha256` 用于文件完整性校验。

## 优先阅读

1. `论文PDF/01_2024_INFOCOM2024_ORANUS：基于随机网络演算的6G O-RAN时延定制化编排_Adamuz-Hinojosa等.pdf`：O-RAN 中的时延保障与无线资源编排。
2. `论文PDF/07_2025_INFOCOM2025_AdaSlicing：开放无线接入网持续网络动态下的自适应在线网络切片_Zhao等.pdf`：持续网络动态下的 RAN 切片分配。
3. `论文PDF/14_2026_INFOCOM2026_DIFFRACT：通过可微编程实现无线网络的神经化效用最大化_Tan等.pdf`：以可微优化处理无线网络效用/资源决策。
4. `论文PDF/15_2026_INFOCOM2026_EExApp：基于图神经网络强化学习的5G O-RAN无线单元能耗优化_Lu等.pdf`：5G O-RAN 无线单元能耗控制。
5. `论文PDF/19_2026_INFOCOM2026_O-DSS：面向中频段蜂窝与雷达共存的开放动态频谱共享框架_Chiejina等.pdf`：蜂窝网络中的动态频谱共享。
